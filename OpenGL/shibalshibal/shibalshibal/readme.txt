공통

h : 은면 제거 토글

w : 와이어/솔리드 토글

s : 전체 초기화

q/ESC : 종료

중앙 큐브(면별 출력)

1~6 : 해당 면 on/off (면별 그리기)

z : 전체 면 켜기

m : 전체 면 끄기

중앙 큐브(이동/축기준 회전)

방향키 : 중앙 큐브 이동

i/k : x축 기준 회전 +/–

j/l : y축 기준 회전 +/–

중앙 큐브(면 애니메이션)

t : 윗면 중심축 회전/멈춤

f : 앞면 열기/닫기

o : 옆면 제자리 회전/멈춤

u : 뒷면 축소/복원 반복

좌측 구 + 우측 큐브(두 객체 모델링 변환 동시에 적용)

x/X : x축 자전 +/-

y/Y : y축 자전 +/-

r/R : 원점 기준 공전 +/-

a/A : 제자리 확대/축소

b/B : 원점 기준 확대/축소(위치도 같이)

d/D : x축 이동 +/-

e/E : y축 이동 +/-
